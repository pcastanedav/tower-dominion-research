## Follow-up inspection: actual construction and selection ordering

`mc_wave60.py` confirms that at each wave start `reserve_full` and the ordinary-reinforcement/special-draft selective flags are computed **before** the optional construction batch. Thus a wave may enter selective mode with a full reserve, construct from that reserve, and then select rewards using the pre-construction mode. This is intentional code behavior to evaluate, not yet confirmed as the desired player policy. After establishment, construction policy options are: `threshold` (build batch when reserve_full), `draft_replenish` (build batch when reserve not full), `continuous` (build from any hand inventory), and `preserve` (only build inventory exceeding reserve target). The two selective flags differ based on `mc_replenish_source`: `draft_only` keeps ordinary reinforcements selective; `reinforcement_only` keeps special drafts selective. Draft scoring deprioritizes MC when the draft-selective flag is active, while `mc_packages.py` gives MC and Amplifier the highest base tier otherwise. This policy must be tested with transition-level assertions before claiming strategic superiority.

## Recovered High Value (HV) draft accounting — confirmed in code

`model/mc_wave60.py` classifies **each selected MC 3A draft** into mutually exclusive `mc_draft_outcomes` counters: `hv_offense` (chosen Blueprint in the selected `PACKAGES[package]`, evaluated tier >=2), `hv_support` (chosen Blueprint in `SUPPORTS`, tier >=2), `hv_other` (other evaluated tier >=2), `mc_reinvestment` (MC selected), `low_value` (other lower-tier choice), or `empty` (no choice). The history snapshot exposes the cumulative counters. `model/sweep_hv_drafts_10_20.py` checks that all six counters sum to `state.drafts_resolved` for each seed and prints `HV_TOTAL = hv_offense + hv_support + hv_other`, along with individual means and MC builds. The experiment explicitly states that support and offense are equally counted. This is a **count of high-value selections**, not a separately calibrated numerical utility function for offense/support. `model/mc_packages.py` has distinct *selection priority ranks*, which must not be confused with these outcome counts. Next: compare offense/support/other counts by establishment target and verify whether the earlier conversation specified any additional HV value formula not present in the current code.
